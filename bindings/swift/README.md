# Controller SDK Swift Bindings

Swift bindings for the Controller SDK, providing native Swift APIs for interacting with the Controller.

## Overview

These Swift bindings wrap the C API generated by Diplomat, providing a type-safe and idiomatic Swift interface for:
- Creating and managing Controllers
- Session management
- Transaction execution
- Error handling

## Building

To build the Swift bindings:

```bash
# From the project root
./scripts/build.sh swift
```

This will:
1. Generate C bindings using Diplomat
2. Build the controller-c library
3. Copy C headers to the Swift package
4. Build the Swift package

## Usage

### Import the Module

```swift
import ControllerSDK
```

### Create a Controller

```swift
let controller = try Controller(
    appId: "myapp",
    username: "testuser",
    classHash: "0x1234...",
    rpcUrl: "https://api.cartridge.gg/x/starknet/sepolia",
    owner: Owner(type: .starknet, privateKey: "0xPrivateKey"),
    address: "0x0",
    chainId: "0x534e5f474f45524c49"
)
```

### Sign Up

```swift
try controller.signup(
    signerType: .starknet,
    sessionExpiration: nil,
    cartridgeApiUrl: nil
)
```

### Execute Transactions

```swift
let call = Call(
    contractAddress: "0x049d36...",
    selector: "transfer",
    calldata: ["0xRecipient", "1000000", "0"]
)

let result = try controller.execute(calls: [call])
```

### Session Account

```swift
let sessionAccount = try SessionAccount(
    rpcUrl: "https://api.cartridge.gg/x/starknet/sepolia",
    signer: Signer(type: .starknet, privateKey: "0xKey"),
    address: "0xAddress",
    username: "user",
    chainId: "0x534e5f474f45524c49",
    sessionAuthorization: "auth_data",
    sessionKeyPair: "key_pair"
)

let result = try sessionAccount.execute(calls: [call])
```

## Error Handling

All SDK methods that can fail throw `ControllerError`:

```swift
do {
    let controller = try Controller.fromStorage(appId: "myapp")
    // Use controller
} catch ControllerError.storageError(let message) {
    print("Storage error: \(message)")
} catch {
    print("Unexpected error: \(error)")
}
```

## Swift Package Manager

To use in your Swift project, you can add it as a local package dependency:

```swift
.package(path: "path/to/bindings/swift/ControllerSDK")
```

Then add to your target dependencies:

```swift
.target(
    name: "YourTarget",
    dependencies: ["ControllerSDK"]
)
```

## Architecture

The Swift bindings use a three-layer architecture:

1. **C Library** (`libcontroller_c.dylib`): Core functionality in Rust/C
2. **C Bridge Module** (`CControllerBridge`): Module map and headers for C interop
3. **Swift Module** (`ControllerSDK`): High-level Swift API

This ensures type safety while maintaining performance and compatibility with the core library.
