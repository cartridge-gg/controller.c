# Controller.c React Native Example

This is a React Native example app demonstrating how to use the Controller.c FFI bindings in a React Native application with Expo.

## Features

- ✨ Key pair generation using Controller.c
- 🔐 Session account creation
- ✍️ Message signing
- 🔗 Starknet integration
- 📱 Works on iOS (Android support coming soon)

## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (>= 20)
- pnpm (`npm install -g pnpm`)
- Xcode (for iOS development)
- CocoaPods (`sudo gem install cocoapods`)
- The Controller.c XCFramework built (see below)

**Note:** 
- This example uses **pnpm** as the package manager (same as arcade-native)
- You don't need to install Expo CLI globally - we use `pnpm exec` to run it locally
- This example uses Expo SDK 54 (same as arcade-native)

## Building the XCFramework

Before running the example, you need to build the Controller.c XCFramework:

```bash
# From the controller.c root directory
cd /path/to/controller.c

# Build the XCFramework for iOS
./scripts/build_ios.sh

# This will create target/controller_uniffi.xcframework
```

## Setup

1. **Install dependencies:**

```bash
cd examples/react-native
pnpm install
```

2. **Install iOS dependencies:**

```bash
cd ios
pod install
cd ..
```

3. **Prebuild the Expo project:**

```bash
pnpm exec expo prebuild
```

This will generate the native iOS and Android projects. The `run.sh` script handles this automatically.

## Running the App

### iOS

```bash
# Start the Metro bundler
pnpm start

# In another terminal, run on iOS
pnpm run ios

# Or directly:
pnpm exec expo run:ios
```

### Android (Coming Soon)

Android support is planned for a future release.

## How It Works

The Controller.c React Native bindings use a multi-layer approach:

1. **Rust Core**: The core Controller logic written in Rust
2. **C FFI**: Generated by UniFFI, provides C bindings
3. **C++ Wrapper**: Bridges C FFI to React Native JSI
4. **JavaScript Bindings**: TypeScript/JavaScript API for React Native

The native module (`Controller.mm`) registers the JSI bindings when the app starts, making the Controller functions available directly in JavaScript.

## API Usage

### Generate Keys

```typescript
import Controller from './modules/controller/src';

// Generate a random private key
const bytes = new Uint8Array(32);
crypto.getRandomValues(bytes);
const privateKey = '0x' + Array.from(bytes)
  .map(b => b.toString(16).padStart(2, '0'))
  .join('');

// Get the public key
const publicKey = Controller.controller.getPublicKey(privateKey);
```

### Create Session Account

```typescript
const account = await Controller.controller.createSession({
  privateKey,
  rpcUrl: 'https://api.cartridge.gg/x/starknet/sepolia',
  chainId: '0x534e5f5345504f4c4941', // SN_SEPOLIA
});
```

### Sign Message

```typescript
const signature = await Controller.controller.signMessage({
  privateKey,
  message: 'Hello from Controller!',
});
```

## Troubleshooting

### "Controller native module not found"

Make sure you:
1. Built the XCFramework (`./scripts/build_ios.sh`)
2. Ran `pod install` in the ios directory
3. Ran `expo prebuild`
4. Rebuilt the app

### Metro bundler issues

Try clearing the cache:

```bash
npx expo start --clear
```

### Build errors

If you encounter build errors:

1. Clean the build:
```bash
cd ios
rm -rf build Pods Podfile.lock
pod install
cd ..
```

2. Rebuild:
```bash
pnpm run ios
```

## Development

### Updating the Bindings

When you make changes to the Controller.c Rust code:

1. Rebuild the bindings:
```bash
cd /path/to/controller.c
cargo build
```

2. Regenerate React Native bindings:
```bash
cargo uniffi-bindgen generate --library target/debug/libcontroller_uniffi.dylib \
  --language react-native \
  --out-dir bindings/react-native
```

3. Copy updated bindings:
```bash
cp -r bindings/react-native/cpp/* examples/react-native/modules/controller/cpp/
cp -r bindings/react-native/ts/* examples/react-native/modules/controller/src/
```

4. Rebuild the app

### Adding New Features

To add new Controller features to the example:

1. Update the Rust code in `src/`
2. Regenerate bindings (see above)
3. Update the example UI in `app/index.tsx`
